# StyleForge — Lesson 9 CSS Architecture Assessment

Demonstrates BEM methodology, centralized CSS custom properties/design tokens, low-specificity selectors, and an ITCSS-inspired stylesheet structure.

## Files
- `index.html` — complete demo page
- `css/01-settings.css` — centralized `:root` tokens
- `css/02-generic.css` — generic/reset rules
- `css/03-elements.css` — element defaults
- `css/04-objects.css` — layout objects
- `css/05-components.css` — BEM components
- `css/06-utilities.css` — utilities
- `css/main.css` — ordered stylesheet entry point
- `docs/validation-report.md` — validation notes

Open `index.html` with VS Code Live Server.
